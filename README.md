## ✨ Tính năng

- ✅ **Single-file** — Toàn bộ HTML, CSS, JS trong 1 file `index.html`
- ✅ **SEO tối ưu** — Meta tags, Open Graph, Twitter Card, Structured Data (JSON-LD)
- ✅ **Responsive** — Hiển thị đẹp trên mọi thiết bị (mobile, tablet, desktop)
- ✅ **Fast load** — Không framework, không dependency, tải dưới 1 giây
- ✅ **Modern UI** — Gradient, animation mượt, glassmorphism header
- ✅ **Accessibility** — Semantic HTML5, ARIA labels, contrast tốt
- ✅ **Zero config** — Deploy trong 2 phút với GitHub Pages

## 🚀 Deploy

### Cách 1: GitHub Pages (Miễn phí)

1. Fork hoặc clone repo này
2. Vào **Settings → Pages**
3. Chọn **Source: Deploy from a branch → main → / (root)**
4. Nhấn **Save** — Website sẽ live sau ~1 phút
